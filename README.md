# Narrate · 叙

> 在喧嚣里，留一处文字自留地。

简约、优雅、阅读优先的 **Halo 2 博客主题**。以编辑杂志的版式组织内容：大字号首屏、编号荐读、克制的朱红点缀与充足留白，让文章本身成为页面的主角。主题移植自 Typecho 主题 **Narrate · 叙**，保留原有视觉语言，并针对 Halo 的模板、设置与插件体系重新实现。

![Narrate · 叙 主题预览](./screenshot.png)

- **Halo 版本**：`>= 2.22.0`
- **主题版本**：`1.0.0`
- **演示站点**：<https://www.puresky.top/>
- **许可证**：[GPL-3.0](./LICENSE)
- **问题反馈**：[GitHub Issues](https://github.com/imorisun/halo-theme-narrate/issues)

## 适用场景

- 个人博客、独立写作站点，尤其是长文、随笔、读书笔记与生活记录
- 希望以杂志式排版呈现内容的站点：精选、荐读、分类导览和编号列表
- 需要深色模式、移动端阅读体验与克制动效的站点
- 已使用「瞬间」「链接管理」「朋友圈」等 Halo 插件，希望前台页面风格统一的站点

## 核心特性

### 编辑杂志风的阅读体验

- **首屏主张**：大字号主张句 + 自动轮播的旋转词，可在主题设置中自定义文案与位置
- **精选与荐读**：首页首篇自动成为主视觉，后续文章以编号列表呈现「编辑荐读」
- **分类导览**：按后台勾选的分类，逐块展示该分类下的最新文章
- **首字水印**：首页、文章页与独立页面以标题首字作为背景装饰，强化版面节奏
- **此刻状态栏**：实时时钟、按访客本地时间切换的分时段问候，以及最新文章入口

### 文章与阅读

- 阅读进度条、预计阅读时长与访问量
- 根据正文 `h2` / `h3` 自动生成文章目录，无标题时自动收窄正文版心
- 代码高亮使用主题内置的 highlight.js 与本地样式，不依赖 CDN
- 正文图片懒加载、自动包裹 `figure`，点击可打开灯箱并支持左右切换
- 标签、版权说明、上一篇 / 下一篇与 Halo 评论组件
- 友链申请区的算术验证码与刷新

### 页面与插件

| 页面               | 说明                                                       |
| ------------------ | ---------------------------------------------------------- |
| 首页               | 首屏、精选、编辑荐读、瞬间、分类导览与分页                 |
| 文章               | 目录、代码高亮、图片灯箱、版权、上下篇、评论               |
| 独立页面           | 标准页面版式，支持留言板场景                               |
| 关于（自定义模板） | 头像、站点统计、站点信息与正文，创建页面时选择「关于」模板 |
| 归档               | 按年月分组，附带文章数量统计                               |
| 分类 / 标签        | 总览页与对应归档页，统一杂志式版式                         |
| 作者               | 作者文章归档                                               |
| 友情链接           | 需「链接管理」插件；支持分组筛选与友链申请说明             |
| 朋友圈             | 需「朋友圈」插件；聚合友站最新文章并分页                   |
| 瞬间列表 / 详情    | 需「瞬间」插件；支持标签筛选、点赞与评论                   |
| 错误页             | 404 与通用错误兜底                                         |

- **搜索**：安装「搜索组件」插件后，导航栏显示搜索按钮，支持 `Ctrl / ⌘ + K` 快捷键
- **深色模式**：跟随系统偏好，也可手动切换；选择保存在浏览器本地，首次渲染前完成初始化以避免闪烁
- **响应式**：桌面多栏布局，移动端提供抽屉导航；尊重 `prefers-reduced-motion`，主要操作可用键盘完成

## 安装

1. 在 [GitHub Releases](https://github.com/imorisun/halo-theme-narrate/releases) 下载最新 ZIP，或在 Halo 应用市场搜索「Narrate」安装。
2. 进入 Halo 后台 → **外观 → 主题 → 安装主题**，上传 ZIP。
3. 启用「Narrate · 叙」，按需在 **主题设置** 中调整文案与开关后保存。
4. 建议在 **外观 → 菜单** 创建主菜单（首页 / 归档 / 分类 / 标签 / 关于），未配置时主题会显示默认导航。

> 主题目录名必须为 `halo-theme-narrate`，与 `theme.yaml` 的 `metadata.name` 保持一致。

## 使用说明与注意事项

- **在线字体**：主题默认从第三方字体服务 `fontsapi.zeoseven.com` 加载 LXGW 975 圆体。若站点访问该服务较慢，可在「品牌与首屏」中关闭，正文会自动回退到苹方、HarmonyOS Sans、微软雅黑或系统字体。
- **文章目录**：仅在正文包含 `h2` / `h3` 时生成；纯图片或短文章会自动使用无目录的窄版心。
- **瞬间页面**：`/moments` 与 `/moments/{name}` 由「瞬间」插件提供路由，主题覆盖其前台模板；未安装插件时这些地址不可用，属于预期行为。
- **友链与朋友圈**：`/links`、`/friends` 分别依赖「链接管理」「朋友圈」插件。
- **评论区**：由 Halo 评论组件渲染；未安装评论插件或文章关闭评论时，会显示「评论已关闭」。
- **深色模式**：访客的手动选择保存在浏览器 `localStorage` 的 `narrate-theme` 键中；清除浏览器数据后会重新跟随系统偏好。
- **系统能力**：站点 Logo、favicon、SEO、统计代码等由 Halo 系统设置或插件负责，主题不重复提供，避免冲突。
- **演示数据**：主题不包含演示文章、分类或图片；安装后展示站点自身内容。
- **升级与卸载**：主题设置保存在 Halo ConfigMap 中，升级不会丢失；卸载主题不会删除文章、页面、分类、标签等站点内容。

## 常见问题

| 问题                   | 处理方式                                                     |
| ---------------------- | ------------------------------------------------------------ |
| 修改设置后页面没有变化 | 在主题列表点击「重载主题配置」，或确认已保存设置             |
| 首页没有瞬间区块       | 安装并启用「瞬间」插件，确认主题设置已开启，且插件中已有内容 |
| 搜索按钮不显示         | 安装并启用「搜索组件」插件                                   |
| 文章页没有目录         | 确认文章正文使用了 `h2` / `h3`，且「显示文章目录」已开启     |
| 字体加载慢或显示异常   | 关闭「启用在线中文字体」，使用系统字体                       |
| 友链页或朋友圈页 404   | 安装并启用对应插件                                           |
| 评论区不显示           | 安装并启用评论组件，并确认文章/页面已开启评论                |
| 关于页样式不对         | 编辑页面，在页面设置中选择「关于」自定义模板                 |

## 兼容性

- 要求 **Halo >= 2.22.0**。底部「备案信息链接」使用了 Halo 2.22 引入的 `array` 设置组件。
- 主题仅影响前台展示，不修改 Halo 核心文件，不依赖数据库结构变更。
- 可选插件未安装、已停用或版本不满足时，相关区块会隐藏或回退到空状态。

## 开发与构建

```bash
pnpm install
pnpm dev     # 监听 src/ 并持续生成 templates/
pnpm build   # 类型检查、构建 templates/ 并打包 dist/halo-theme-narrate-1.0.0.zip
```

- `src/` 是源码目录：页面 HTML、`partials/` 片段、CSS 与 TypeScript。
- `templates/` 是构建产物，Halo 只读取主题根目录下的 `templates/`，请勿手工修改。
- 主题元数据见 `theme.yaml`，设置表单见 `settings.yaml`，移植记录见 [MIGRATION.md](./MIGRATION.md)。
