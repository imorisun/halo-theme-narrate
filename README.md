# Narrate · 叙

> 在喧嚣里，留一处文字自留地。

简约、优雅、阅读优先的 **Halo 2 博客主题**。以编辑杂志的版式组织内容：大字号首屏、编号荐读、克制的朱红点缀与充足留白，让文章本身成为页面的主角。主题移植自 Typecho 主题 **Narrate · 叙**，保留原有视觉语言，并针对 Halo 的模板、设置与插件体系重新实现。

## 适用场景

- 个人博客、独立写作站点，尤其是长文、随笔、读书笔记与生活记录
- 希望以杂志式排版呈现内容的站点：精选、荐读、分类导览和编号列表
- 需要深色模式、移动端阅读体验与克制动效的站点
- 已使用「瞬间」「链接管理」「朋友圈」「图库管理」等 Halo 插件，希望前台页面风格统一的站点

## 核心特性

### 编辑杂志风的首页

- **首屏主张**：大字号主张句 + 自动轮播的旋转词；眉题、背景大字、站点英文标语与页脚标语均可在主题设置中修改
- **站点概览**：文章、分类、标签数量滚动计数，附「开始阅读」与「归档全部」入口
- **此刻状态栏**：实时时钟、按访客本地时间切换的分时段问候，以及按发布时间排序的最新文章入口
- **精选与荐读**：首页首篇自动成为主视觉（置顶文章标注「置顶精选」），后续文章以编号列表呈现「编辑荐读」（最多 4 篇）
- **分类导览**：按后台勾选的分类逐块展示，每块含编号、英文标识、分类简介与最新 4 篇文章；未选择分类时整块隐藏
- **瞬间横滑**：安装「瞬间」插件后，首页以横向轨道展示最新瞬间，末端提供「查看全部瞬间」入口
- **首字水印**：首页使用可配置的背景大字，文章页与独立页面以标题首字作为背景装饰，强化版面节奏
- **首页不分页**：只按版式呈现站点当前内容，不提供分页入口

### 阅读体验

- 顶部阅读进度条、按字数估算的阅读时长（约 350 字 / 分钟）与访问量
- 根据正文 `h2` / `h3` 自动生成目录：桌面端显示右侧栏目录，平板与手机使用可折叠目录，滚动时高亮当前章节；无标题时正文自动收窄版心
- 正文图片懒加载并自动包裹 `figure`，首图提升加载优先级；点击可打开灯箱，支持按钮、键盘 `←` / `→` 切换，`Esc` 关闭并将焦点归还
- 代码高亮由 Halo 插件（如 Shiki 代码高亮）提供，主题不内置高亮脚本与样式
- 多分类展示、标签、版权说明、上一篇 / 下一篇与 Halo 评论组件
- 深色模式下同步 Halo 插件组件的配色方案

### 无刷新浏览

- 基于 [Swup](https://swup.js.org/) 的页面过渡：页头、页脚与已加载脚本常驻，仅替换 `main` 内容，减少整页刷新
- 顶部细进度条提示加载状态，并预加载即将访问的链接
- 切换时同步 `<head>` 中的标题与静态资源，等待样式加载完成再替换，避免闪样式
- 为屏幕阅读器播报新页面标题，尊重 `prefers-reduced-motion`
- 分页跳转后回到列表区域，常规跳转回到页面顶部；同页锚点保留平滑滚动
- 禁用 JavaScript 时自动退化为常规整页跳转

### 导航与全局

- **多级菜单**：支持后台菜单的任意层级子菜单，桌面端悬停 / 聚焦展开，移动端与页脚点击箭头展开，`Esc` 或点击空白处收起
- **分组标签**：指向首页或无链接的菜单项渲染为不可点击的分组标题，不参与选中态
- **搜索**：安装「搜索组件」插件后，导航栏显示搜索按钮，支持 `Ctrl / ⌘ + K` 快捷键
- **深色模式**：跟随系统偏好，也可手动切换；选择保存在浏览器本地，首次渲染前完成初始化以避免闪烁
- **响应式**：桌面多栏布局，移动端提供抽屉导航与折叠目录
- **可访问性**：主要操作可用键盘完成，统一 `:focus-visible` 焦点环，弹层关闭后还原焦点
- **轻动效**：滚动浮现、数字增长与旋转词动画，在减少动态偏好下自动降级
- **回到顶部**：滚动一定距离后出现，平滑返回顶部
- **页脚**：品牌区、导航、全部分类、随机友链、版权信息、驱动信息与备案链接

## 安装

1. 在 [GitHub Releases](https://github.com/imorisun/halo-theme-narrate/releases) 下载最新 ZIP，或在 Halo 应用市场搜索「Narrate」安装。
2. 进入 Halo 后台 → **外观 → 主题 → 安装主题**，上传 ZIP。
3. 启用「Narrate · 叙」，按需在 **主题设置** 中调整文案与开关后保存。
4. 建议在 **外观 → 菜单** 创建主菜单（首页 / 归档 / 分类 / 标签 / 关于），未配置时主题会显示默认导航；菜单支持任意层级子菜单。

> 主题目录名必须为 `halo-theme-narrate`，与 `theme.yaml` 的 `metadata.name` 保持一致。

## 使用说明与注意事项

- **内置字体**：主题随包分发 LXGW 975 圆体（OFL-1.1），按 `unicode-range` 分片，浏览器只下载当前页面用到的分片，不请求第三方服务。若不需要，可在「品牌与首屏」中关闭，正文会自动回退到苹方、HarmonyOS Sans、微软雅黑或系统字体。
- **文章目录**：仅在正文包含 `h2` / `h3` 时生成；纯图片或短文章会自动使用无目录的窄版心。
- **无刷新导航**：页面切换由 Swup 接管，只替换 `main` 内容（`#swup` 容器），并重新执行内容区域内的第三方脚本；禁用 JavaScript 或浏览器不支持时回退为整页跳转。
- **瞬间页面**：`/moments` 与 `/moments/{name}` 由「瞬间」插件提供路由，主题覆盖其前台模板；未安装插件时这些地址不可用，属于预期行为。
- **友链与朋友圈**：`/links`、`/friends` 分别依赖「链接管理」「朋友圈」插件。
- **图库**：`/photos` 与 `/photos/{name}` 依赖「图库管理」插件，支持分组筛选与拍摄信息展示。
- **豆瓣**：`/douban` 由「豆瓣」插件提供路由，主题覆盖其前台模板；需在插件设置中配置豆瓣 ID 并完成数据同步，筛选与分页均读取插件同步的收藏数据。
- **装备**：`/equipments` 由「装备管理」插件提供路由，主题覆盖其前台模板；分组筛选通过 `?group=` 查询串完成，分页为 `/equipments/page/{page}`，每页条数读取插件设置。
- **轻言**：`/hitokoto` 由「轻言」插件提供路由，主题同时覆盖其「经典」与「液态玻璃」两套前台模板，统一使用主题页头页脚与明暗色；主句、分类筛选、换一句、点赞与分享链接均由主题实现，`?sentence=` 分享直达保持可用。
- **菜单层级**：后台菜单的任意层级子菜单都会渲染，桌面端悬停展开，移动端点击箭头展开；指向首页的菜单项一律视为分组标签。
- **评论区**：由 Halo 评论组件渲染；未安装评论插件或文章关闭评论时，会显示「评论已关闭」。
- **深色模式**：访客的手动选择保存在浏览器 `localStorage` 的 `narrate-theme` 键中；清除浏览器数据后会重新跟随系统偏好。
- **关于页头像**：优先使用站点图标，未设置时回退到主题内置头像。
- **系统能力**：站点 Logo、favicon、SEO、统计代码等由 Halo 系统设置或插件负责，主题不重复提供，避免冲突。
- **界面语言**：主题文案为简体中文，暂未提供多语言资源。
- **演示数据**：主题不包含演示文章、分类或图片；安装后展示站点自身内容。
- **升级与卸载**：主题设置保存在 Halo ConfigMap 中，升级不会丢失；卸载主题不会删除文章、页面、分类、标签等站点内容。

## 常见问题

| 问题                   | 处理方式                                                        |
| ---------------------- | --------------------------------------------------------------- |
| 修改设置后页面没有变化 | 在主题列表点击「重载主题配置」，或确认已保存设置                |
| 首页没有瞬间区块       | 安装并启用「瞬间」插件，确认主题设置已开启，且插件中已有内容    |
| 搜索按钮不显示         | 安装并启用「搜索组件」插件                                      |
| 文章页没有目录         | 确认文章正文使用了 `h2` / `h3`，且「显示文章目录」已开启        |
| 字体加载慢或显示异常   | 关闭「启用内置中文字体」，使用系统字体                          |
| 友链页或朋友圈页 404   | 安装并启用对应插件                                              |
| 豆瓣页没有记录         | 安装并启用「豆瓣」插件，配置豆瓣 ID 后在后台执行一次数据同步    |
| 轻言页没有句子         | 安装并启用「轻言」插件，在后台「工具 → 轻言管理」添加并发布句子 |
| 评论区不显示           | 安装并启用评论组件，并确认文章/页面已开启评论                   |
| 关于页样式不对         | 编辑页面，在页面设置中选择「关于」自定义模板                    |
| 点击菜单没有任何跳转   | 指向首页或无链接的菜单项为分组标签，需在其下添加子菜单          |
| 页面跳转没有整页刷新   | Swup 无刷新过渡属预期行为；可通过刷新页面回到常规加载           |

## 兼容性

- 要求 **Halo >= 2.27.0**（见 `theme.yaml` 的 `spec.requires`）。底部「备案信息链接」使用了 Halo 2.22 引入的 `array` 设置组件。
- 主题仅影响前台展示，不修改 Halo 核心文件，不依赖数据库结构变更。
- 可选插件未安装、已停用或版本不满足时，相关区块会隐藏或回退到空状态。
- 依赖 ES Module、CSS 变量、`IntersectionObserver` 等现代浏览器特性；建议使用较新版本的 Chrome、Edge、Firefox 或 Safari。无刷新过渡在 JavaScript 不可用时自动降级为整页跳转。

## 开发与构建

环境要求：**Node.js >= 20.19.0**、**pnpm 10.33.0**（见 `package.json` 的 `engines` 与 `packageManager`）。

```bash
pnpm install
pnpm dev        # 监听 src/ 并持续构建 templates/
pnpm build      # 类型检查 + 构建 templates/ + 打包 dist/halo-theme-narrate-2.2.0.zip
pnpm build-only # 仅类型检查与构建，不打包 ZIP
pnpm check      # 格式化、Lint 与类型检查，并自动修复可修复问题
```

- `src/`：页面模板；`src/partials/` 为布局、侧栏与分页等公共片段。
- `src/css/`：按模块拆分的样式；`src/js/`：交互源码，包含 Swup 页面过渡、目录、灯箱、搜索、导航与各插件页面逻辑。
- `public/`：原样复制到 `templates/` 的静态资源，如内置头像、字体与 `lxgw.css`。
- `templates/`：构建产物，Halo 只读取主题根目录下的 `templates/`，请勿手工修改。
- `theme.yaml`：主题元数据；`settings.yaml`：主题设置表单。
- `scripts/package.mjs`：打包时临时移走 `pnpm-lock.yaml`，避免锁文件被 `theme-package` 误打进主题包。
- `.github/workflows/ci.yaml`：拉取请求与主分支推送时执行 `vp check` 与构建校验。
- `.github/workflows/cd.yaml`：发布 GitHub Release 后自动构建 ZIP、上传至 Release 并同步 Halo 应用市场。
